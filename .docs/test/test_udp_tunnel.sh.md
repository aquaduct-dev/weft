## TL;DR
This script performs an end-to-end integration test to verify that UDP traffic is correctly tunneled through the Weft server infrastructure.

It orchestrates four distinct processes: a Python UDP echo server, the Weft server, and a Weft tunnel client. The script dynamically allocates free ports for each component to avoid conflicts. It retrieves a connection secret generated by the Weft server to authenticate the tunnel connection. Finally, it sends a test packet through the tunnel and validates that the echo response matches the expected payload, ensuring the full stack functions correctly.
