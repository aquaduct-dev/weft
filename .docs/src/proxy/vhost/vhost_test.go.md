## TL;DR
This file contains Ginkgo unit tests for the VHost proxy routing, TLS management, and HTTP/3 Alt-Svc header logic.

The test suite validates `VHostProxy` behavior by injecting mock upstreams and verifying response codes and bodies. It covers standard HTTP forwarding, HTTPS termination with dynamically generated certificates, and 404 handling for unknown hosts. The `WGAwareRoundTripper` tests ensure transport reuse to prevent goroutine leaks, confirming that a custom dialer is only used for WireGuard targets when a device is provided. Finally, the `Alt-Svc` section verifies that the `h3` advertisement header is present only when the internal HTTP/3 server is active, ensuring correct protocol negotiation signaling.
