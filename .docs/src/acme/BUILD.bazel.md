## TL;DR
This file defines the Bazel build targets for the ACME package, which handles certificate issuance and HTTP-01 challenge validation.

The `go_library` target compiles the core logic in `acme.go`, `challenge_proxy.go`, `fresh_lookup.go`, `http01_only.go`, and `testing_helpers.go`. It exposes the package publicly and depends on `zerolog` for logging and `golang.org/x/crypto/acme` for protocol implementation. The `http01_only.go` source enforces HTTP-01 challenges exclusively to prevent failures with round-robin DNS setups where TLS-ALPN-01 would fail across nodes. The `challenge_proxy.go` source implements peer-to-peer proxying for challenges when the validating CA lands on a node that did not initiate the order, avoiding redirect issues.

The `go_test` target runs the test suite using Ginkgo and Gomega. It embeds the library and includes tests for rate limiting, host resolution, and peer fallback mechanisms. The rate limit handling ensures that if the CA returns a retry-after header, subsequent requests for that host are served locally without contacting the CA until the limit expires.
